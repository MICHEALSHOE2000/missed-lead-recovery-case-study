01 / Business problem

A trusted shop that only worked face to face.

Mikee Gadget Plug sells UK-used and brand-new phones, laptops, tablets, watches and audio gear from a physical shop in Computer Village, Ikeja, one of West Africa's largest electronics markets. Before this project, sales came from people who visited the shop or messaged on WhatsApp. Prices lived in chat threads, so every buyer started the same back-and-forth.

Selling online in Nigeria meant solving problems a standard storefront template doesn't cover:

Trust

Used phones carry risk

Buyers worry about fake parts, swapped screens and weak batteries. The site had to earn the trust a shop counter gets for free.

Affordability

Most buyers can't pay ₦1M+ at once

Flagship phones cost more than many monthly salaries. Instalment plans and trade-ins decide whether a sale happens.

Logistics

36 states, many delivery models

Lagos gets doorstep delivery priced by local government area. Other states ship through transport parks. Some buyers want to collect in store.

Operations

A non-technical team runs it

Prices change daily with the market. The person updating them every day is not a developer, so the admin had to be plain and safe to use.

02 / My responsibilities

From the business plan to the database.

I own the business and built its platform, so I made the product calls and handled the engineering. On an agency team, that maps to these roles:

  • Product and UX. Defined the buying journeys (buy outright, Pay Small Small, swap and upgrade), the information architecture and the content.
  • Frontend. Built a responsive storefront, product pages, cart, checkout, swap calculator and financing flow in modern JavaScript.
  • Backend and data. Designed the Supabase schema, wrote 18 versioned SQL migrations, each with a rollback script, and built serverless APIs for checkout, payments and the admin.
  • Payments. Integrated Paystack, Credit Direct and bank transfer, with server-side amount checks and signed webhooks.
  • DevOps. Set up GitHub with a pull-request workflow, Vercel preview and production deploys, environment variables per environment, and a custom domain.
  • Growth. Built SEO landing pages, structured data, a Google Merchant Center feed and TikTok Pixel event tracking.

I wrote the specs and acceptance criteria, reviewed every change, tested it and approved every production release myself. I used AI pair-programmers (ChatGPT, then Claude) to move faster. No code reached customers until it passed the test suite and my review.

03 / Technical architecture

Static-first speed, live data where it counts.

Many buyers in Nigeria shop on mid-range Android phones over mobile data, so speed came first. A Node build pipeline turns one product catalogue into hundreds of static HTML pages. These serve instantly from Vercel's CDN and stay readable with JavaScript turned off. Live data from the database is added only where it changes the decision, such as prices, deals and availability.

Why no framework?

The site is mostly content and forms. Prebuilt HTML with small ES modules sends less JavaScript than a single-page app, needs no hydration and keeps SEO simple. The build still gets the benefits of a component system through shared render functions.

Built to fail safe

If the database is slow, the Edge Middleware times out after 2 seconds and serves the prebuilt page. Shoppers always get a working store, and the prebuilt price is never more than one build old.

04 / Frontend development

Designed for a phone in one hand.

Most traffic is mobile, so every journey was designed at 390px first. Phone layouts get a fixed bottom bar for Home, Shop, Categories, Cart and WhatsApp. Variant pickers show the price of each storage option on the button itself, so shoppers never have to guess.

  • Search, filters (brand, UK Used or Brand New, category) and sorting across 14 categories
  • Cart, saved items and order tracking, with a customer account page
  • Checkout with Nigerian State → LGA selection, phone-number rules and email typo suggestions
  • Checked for horizontal overflow at 320, 375, 390, 430, 768 and 1440px, with skip links and visible focus states
  • Lazy-loaded imagery, explicit image cache headers and a WebM/MP4 hero video with a poster fallback

05 / Supabase

A database a retailer can trust with live money.

Supabase Postgres holds the catalogue, orders, payment events, delivery rates, deals, reviews and the AI assistant's conversations. The browser never gets privileged access. All writes go through server functions that hold the service key, and every table has row-level security switched on.

Schema

30 tables, versioned

Inventory with 603 sellable rows, orders and line items, payment and instalment events, 56 delivery rates across Lagos LGAs and states, and an admin audit log.

Change safety

Migrations you can undo

18 timestamped migrations. Each risky data change ships with a rollback SQL file and a backup table, so bulk price updates can be reversed in seconds.

Security

Admin access checked on the server

Admin access is checked against a confirmed identity on the server, never against user-editable metadata. Tests enforce this.

Logic in the database

RPC functions

Postgres functions handle atomic jobs such as marking an order paid, rate-limiting the AI assistant and tracking its spend against a monthly budget in naira.

06 / Vercel

Ship small, preview everything, roll back fast.

  • Git-driven releases. Every feature lands on a branch, gets a preview URL and merges to main by pull request. The latest production release is PR #51.
  • Quality gate. npm run check runs syntax checks on 84 modules, rebuilds every page, validates all internal links and tracking events, and then runs the test suite.
  • Edge Middleware. Adds Hot Deals and live product data to the first HTML response, so Google and social previews see current prices.
  • Serverless functions for checkout, payment verification, webhooks, admin and the assistant. Secrets are kept in separate Preview and Production environment variables.
  • Custom domain mikeegadget.com.ng with www, SEO-safe 301 redirects for retired URLs, and instant rollback to any earlier deployment.

07 / Payment integrations

Three ways to pay, one source of truth.

The server never trusts a price from the browser. Checkout recalculates the total from the database, and an order is marked paid only after the server verifies the payment provider's response.

08 / Customer experience

A salesperson that never closes.

Mikee AI is a chat assistant that answers like the shop's best salesperson. It recommends phones from the live catalogue, explains UK Used versus Brand New, and works out a swap top-up from the customer's current phone and its condition.

It uses OpenAI function calling against the store's own data, so prices always come from the catalogue. They are never made up by the model.

Business rules come first. Any price negotiation goes to the owner. A Face ID fault triggers an in-store inspection instead of a quote. When a customer asks for a person, staff can reply from the admin, which pauses the AI for that chat.

Cost is controlled. A naira budget cap and a daily call limit switch it back to a scripted demo mode before spending can run away. Chats are deleted after 30 days, or after 180 days if the customer shares contact details.

Trust built into the interface

The 7-day warranty, test before you pay, store address with directions, and a battery-health guide appear on every page. The fears behind abandoned carts are answered before checkout.

Admin built for one non-technical user

The store manager uses plain-language tabs for Orders, Reservations, Prices, Hot Deals, Photos, Reviews and Mikee AI. Bulk price changes are shown for confirmation before they go live.

09 / Marketing & business growth

Built to be found, measured and sold through.

I built the store as a growth channel as well as a catalogue. Each feature answers a question a marketer would ask: how do people find us, what convinces them, and how do we know it worked?

SEO

Pages that match real searches

23 landing pages match local searches like "used iPhones Lagos" and "phones on installment". There are 125 product pages and a 262-URL sitemap. Product, Offer, FAQ and Breadcrumb structured data appears on 267 pages.

Shopping

Google Merchant Center feed

A product feed built from the same database as the site, with live price, availability, condition and delivery data. An admin report flags products that aren't eligible.

Measurement

Tracking events that can't silently break

TikTok Pixel events fire on key funnel steps. The build fails if a required tracking event goes missing from a landing page.

Merchandising

Levers the owner can pull

Admin-picked Hot Deals at 10% off with the old price crossed out, a rotating category showcase and featured new arrivals, all changed without a deploy.

10 / Outcome & what's next

A shop counter became a national storefront.

  • Live at mikeegadget.com.ng, selling across 14 product categories with nationwide delivery and store pickup
  • Four ways to complete a purchase, including instalments, which are a must-have for this market
  • Daily price and deal updates handled by non-technical staff, with no developer needed
  • 199 automated tests guarding the logic that handles money: pricing, instalments, swap values and payment verification

Next: live Paystack card payments once the review clears, Google Shopping ads on top of the free listings, and Mikee AI on WhatsApp through the official Cloud API, for which the signed-webhook handler is already built.
